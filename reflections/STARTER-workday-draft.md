# Workday Reflection Draft

> **Starter template.** Run `/draft-reflection` to start a guided walkthrough that helps you produce a high-quality reflection for your current fiscal half. The walkthrough covers peer feedback outreach, evidence gathering from your portfolio and external sources, first draft generation, optional pressure testing by a senior-leader persona, and finalization. The command will create a properly named file (e.g., `FY26-H2-workday-draft.md`) and save any peer feedback you provide along the way. You can delete this starter file once your first real draft exists.

Run `/draft-reflection` to begin. The walkthrough will guide you through each step.
