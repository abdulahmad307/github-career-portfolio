# Impact Inbox

Use this folder for optional discovery candidates from sources you choose to provide.

The impact inbox is not your evidence record. It is a review queue. A candidate becomes evidence only after you decide to save it as an impact note, feedback entry, goal update, manager-calibration ask, or private note.

Good candidate sources include specific PRs, issues, discussions, project updates, docs, stakeholder comments, changelog snippets, screenshot notes, meeting notes, or pasted excerpts. Avoid broad source dumps. Discovery works best when you provide a focused source set and a short note about what you want reviewed.

Candidate files should answer:

- What source did this come from?
- What might be the impact or feedback signal?
- What context is missing?
- What should happen next: save, ask follow-up, keep private, or ignore?

Run `/discover-impact` when you want Copilot to help organize candidate signals before you decide what belongs in the portfolio.
