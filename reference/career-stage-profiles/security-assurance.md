Career Stage Profile
Job Family Group: Security
Job Family: Security Assurance
Job Family Definition Analyzes issues to identify security problems and develop solutions to mitigate security issues. Contributes to
security designs (e.g., design reviews, threat models). Evaluates products against security baselines (e.g., gap
analysis), assessing security risks and their impact on affected services. Identifies, prioritizes, and manages security
issues that cause negative impact to customers, responding to security events, potential vulnerabilities,
exposures, and policy compliance issues. Engages with internal and/or external customers and partners to
improve security issues and analyze security concerns or patterns. Ensures best practices for security architecture,
design, and development are in place. Provides regular updates on security status or concerns to leadership to
ensure leaders have accurate risk assessments. Researches, analyzes, and summarizes security threats to
raise awareness and collaborate with relevant stakeholders. Translates technical information to nontechnical
audiences to effectively communicate security risks, informing relevant stakeholders of security risks as needed.
Works with various stakeholders to engender trust in GitHub products and address security concerns. Provides
guidance on improving tooling and automation from a security perspective, contributing to long-term security
solutions for the organization.

- P2 - P6 (G7 - G11)
