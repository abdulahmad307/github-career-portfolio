## Role definition

Designs solutions to address identified control issues (e.g., network, identity, application
security). Identifies opportunities and makes recommendations to improve security posture (e.g.,
streamline processes, automate) and proactively prevent attacks. Identifies opportunities and
creates automation to improve efficiency and effectiveness, creating new capabilities/solutions in
service of security outcomes. Implements and improves security policy, standards, and best
practices, developing and refining plans, security controls, and solutions to protect
confidentiality, integrity, and availability of networks, systems, and data. Educates and engages
with others (e.g., internal teams, external partners) to drive consistency and awareness of security
risk, best practices, and standards. Translates technical information to nontechnical audiences to
effectively communicate security risks, collaborating across the organization to address security
risks and define new requirements and feature sets. Recommends and implements mitigation strategies
based on trends identified in the analysis of key metrics, key performance indicators, and other
data sources.

## Grade progression summary

| Profile | Grade | Scope signal from profile summary |
|---|---|---|
| P2 | G7 | Using existing systems, monitors existing controls against security requirements. Implements new automation with limited guidance. Upholds controls to enable enforcement of security policy, standards, and best practices and escalates identified gaps in policy as needed. |
| P3 | G8 | Identifies and investigates potential issues in controls. Identifies and raises opportunities for automation to improve efficiency and effectiveness. Implements security policy, standards, and best practices, escalating issues and recommending mitigations accordingly to address identified gaps. |
| P4 | G9 | Designs solutions to address identified control issues. Identifies and raises opportunities for automation to improve efficiency and effectiveness. Contributes to and maintains accurate and comprehensive security policy, standards, and best practices. |
| P5 | G10 | Designs solutions to address identified control issues. Leads the creation of automation to drive greater efficiencies. Drives strategic improvements across partner and stakeholder teams in security policy, standards, and best practices. |
| P6 | G11 | Drives collaboration among resources needed to address identified issues. Leads the creation of automation to drive greater efficiencies. Sets strategy for security policy, standards, and best practices and serves as a technical expert for the development and implementation of security policy for the organization. |
| M3 | G8 | Directs team to address identified security gaps. Drives teams to identify, recommend, and implement new automation to create greater efficiencies and effectiveness of security operations. Escalates and drives resolution of potential gaps in security policy, standards, and best practices for the organization. |
| M4 | G9 | Prioritizes security gaps for teams and leadership to ensure issues are properly addressed and mitigated. Prioritizes automation efforts across teams and secures resources to develop and implement automation. Prioritizes and selects efforts around development and implementation of security policy, standards, and best practices. |
| M5 | G10 | Establishes accountabilities for a team or teams and leaders to execute security controls and countermeasures needed to uphold security standards. Drives team outcomes in identifying, recommending, developing, and implementing automation to improve efficiency and effectiveness of security operations. |
| M6 | G11 | Establishes accountabilities for a team or teams and leaders across the organization to execute security controls and countermeasures needed to uphold security standards. Drives outcomes with impact across the organization in identifying, recommending, developing, and implementing automation to improve efficiency and effectiveness of security operations. |
