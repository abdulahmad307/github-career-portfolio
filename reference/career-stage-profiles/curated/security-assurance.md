## Role definition

Analyzes issues to identify security problems and develop solutions to mitigate security issues.
Contributes to security designs (e.g., design reviews, threat models). Evaluates products against
security baselines (e.g., gap analysis), assessing security risks and their impact on affected
services. Identifies, prioritizes, and manages security issues that cause negative impact to
customers, responding to security events, potential vulnerabilities, exposures, and policy
compliance issues. Engages with internal and/or external customers and partners to improve security
issues and analyze security concerns or patterns. Ensures best practices for security architecture,
design, and development are in place. Provides regular updates on security status or concerns to
leadership to ensure leaders have accurate risk assessments. Researches, analyzes, and summarizes
security threats to raise awareness and collaborate with relevant stakeholders. Translates technical
information to nontechnical audiences to effectively communicate security risks, informing relevant
stakeholders of security risks as needed. Works with various stakeholders to engender trust in
GitHub products and address security concerns. Provides guidance on improving tooling and automation
from a security perspective, contributing to long-term security solutions for the organization.

## Grade progression summary

| Profile | Grade | Scope signal from profile summary |
|---|---|---|
| P2 | G7 | Begins to analyze threat trends and anomalies to determine operational impact. Identifies security defects or vulnerabilities and escalates as needed. Develops expertise in a class or set of security issues, tools, mitigations, and processes. Begins to address security issues with internal and/or external customers and partners. |
| P3 | G8 | Performs end-to-end security analysis on a solution or application, including a search for given vulnerabilities across multiple solutions and/or applications and recommends potential mitigation strategies. Identifies, prioritizes, and manages underlying causes of security shortcomings. |
| P4 | G9 | Analyzes complex issues using multiple data sources to identify security problems. Identifies, prioritizes, and manages moderately complex security issues that cause negative impact to customers. Applies subject matter expertise to identify potential security issues, tools, mitigations, and processes. |
| P5 | G10 | Proactively analyzes highly complex issues using multiple data sources to identify security problems. Identifies, prioritizes, and manages complex security issues that cause significant negative impact to customers. Helps others by sharing expertise to identify potential security issues, tools, mitigations, and processes. |
| P6 | G11 | Analyzes highly complex issues using multiple data sources to identify security problems. Identifies, prioritizes, and targets highly complex security issues that cause significant negative impact to customers. Serves as an expert resource for the organization to identify potential security issues, tools, mitigations, and processes. |
| M3 | G8 | Coaches team members to uphold standards of analysis and design. Contributes to crafting standards to address security issues, providing guidance to others as needed. Applies subject matter expertise in a class or set of security issues to ensure work is properly resourced and prioritized. |
| M4 | G9 | Ensures work of the team upholds standards of analysis and design. Contributes to crafting standards to address moderately complex security issues, providing guidance to others as needed. Leads the work of technical experts and leverages expertise across a spectrum of specialties to ensure work is properly resourced and prioritized. |
| M5 | G10 | Ensures work of the team upholds standards of analysis and design. Recognizes and conveys the impact of security problems. Crafts standards to address complex security issues, influencing standards within and outside GitHub. Leads the work of technical experts and leverages expertise across a spectrum of specialties to ensure work is properly resourced and prioritized. |
| M6 | G11 | Ensures work of the team upholds standards of analysis and design. Recognizes and conveys the impact of security problems. Crafts standards to address highly complex security issues, influencing standards within and outside GitHub. |
