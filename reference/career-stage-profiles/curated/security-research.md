## Role definition

Identifies, conducts, and supports others in conducting research into critical security areas,
current attacks, adversary tracking, and academic literature. Works with others to synthesize
research findings into recommendations for mitigation of security issues. Shares across teams.
Analyzes complex issues using multiple data sources to develop insights and identify security
problems and threats. Suggests, and when necessary, implements new solutions to mitigate security
issues. Makes tradeoffs to balance security and operational needs. Synthesizes vulnerability data to
generate trends, patterns and insights. Leads efforts to clean, structure, and standardize data and
data sources. Leads data quality efforts to ensure timely and consistent access to data sources.
Identifies, prioritizes, and targets complex security issues that cause negative impact to
customers. Engages with customers and partners to improve security issues. Helps to make connections
and assist in developing agreements between groups to clarify priorities and identify dependencies.
Provides coordination across groups. Applies diagnostic expertise, provides guidance to other
engineers working to mitigate and resolve issues and contributes to quality postmortem and root
cause analysis processes across teams. Uses subject matter expertise to identify potential security
issues, tools, mitigations, and processes (e.g., architecture, failure modes, attack chain, threat
modeling, vulnerabilities).
