## Role definition

Works with stakeholders to determine system requirements to be able to design and build for scale
while managing dependencies. Creates, troubleshoots, and reviews code to be able to implement for
systems. Leverages expertise across system features and partners with appropriate stakeholders on
project plans and work items. Monitors systems for reliability and supportability through active
live site maintenance, incident response during interruptions, integration of instrumentation for
gathering system telemetry, and conducting related data analysis. Drives engineering excellence by
adhering to compliance standards, partnering with key partners, and driving continuous improvement
across systems.

## Grade progression summary

| Profile | Grade | Scope signal from profile summary |
|---|---|---|
| P2 | G7 | Contributes in partnership with appropriate stakeholders to determine system requirements. Begins to demonstrate understanding of systems integration architecture in applicable platforms. With guidance, learns create and implement code for a product, service, or feature, reusing code when applicable. |
| P3 | G8 | Works with appropriate stakeholders to determine system requirements. Demonstrates understanding of systems integration architecture in applicable platforms. Creates and implements code for a product, service, or feature, reusing code when applicable. Contributes to the development of automation within production and deployment of a system. |
| P4 | G9 | Collaborates with appropriate stakeholders to determine system requirements. Demonstrates deep understanding of systems integration architecture in applicable platforms. Leads by example within the team by producing extensible and maintainable changes to the system to improve efficiencies. |
| P5 | G10 | Partners with appropriate stakeholders to determine system requirements. Provides expert understanding of systems integration architecture in applicable platforms and sets system strategy. Mentors others to produce extensible and maintainable changes to the system to improve efficiencies across systems. |
| M4 | G9 | Coaches and supports partnership with appropriate stakeholders to determine system requirements. Coaches others and leads discussions for systems integration architecture in applicable platforms. Coaches team members within the team when reducing extensible and maintainable changes to the system to improve efficiencies. |
| M5 | G10 | Guides partnership with appropriate stakeholders to determine system requirements. Guides teams and leads overall integration architecture in applicable platforms. Guides team within and across teams when producing extensible and maintainable changes to the system to improve efficiencies. |
| M6 | G11 | Oversees partnership with appropriate stakeholders to determine system requirements. Drives overall plan for integration of architecture in applicable platforms. Oversees team members within and across teams producing extensible and maintainable changes to the system to improve efficiencies. |
