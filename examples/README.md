# Synthetic examples

These examples are synthetic calibration material. They are not real employee evidence, not copied from a private portfolio, and not meant to be pasted into Workday, manager conversations, or promotion materials.

Use them when you want to understand what a strong input or output can look like before adding your own career evidence.

## How to use these examples

1. Read the example that matches your current workflow.
2. Notice the structure, level of specificity, privacy boundaries, and source handling.
3. Run the matching command in your private repo with your own real evidence.
4. Do not copy names, projects, metrics, scenarios, or wording from the synthetic example into your real artifacts.

## Example safety checklist

Before adding or updating an example, confirm:

- The file states that the example is synthetic.
- It includes purpose, scenario, input, output, why it works, privacy note, and reuse path.
- It does not include real names, issue numbers, PR numbers, Slack URLs, customer names, or recognizable internal incidents.
- It does not copy details from a real private portfolio, Workday export, or private calibration PDF.
- It tells Copilot and the user to treat synthetic content as a pattern only, not factual evidence.

## AI guidance

Copilot may read these examples for structure and calibration. Copilot must not treat them as evidence about the user, must not cite them as user accomplishments, and must not copy synthetic details into real impact notes, feedback entries, manager prep, reflection drafts, manager reflection replies, promotion readiness coaching, or promotion materials.
