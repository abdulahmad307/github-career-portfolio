# Synthetic example: promotion readiness coaching

This example is synthetic. It is not a real promotion case, manager calibration, or readiness assessment.

## Purpose

Show how `/prep-promotion` can coach promotion readiness by comparing portfolio evidence against role expectations, identifying strengths and gaps, shaping the impact narrative, and keeping employee readiness, business need, budget availability, and role-reference coverage separate.

## Scenario

The user is exploring whether a workflow-improvement project might support a future promotion conversation. The user's career profile has a known job family and target grade, but the role reference is raw rather than curated.

## Input

```text
Prep promotion readiness from my kickoff checklist work. I want to know how I stack up, what is strong, what is missing, and what I should ask my manager next.
```

## Output

```md
### Source and Reference Coverage

- Role context: Job family and target grade found in `growth-plan/career-profile.md`.
- Role-reference coverage: `Raw reference available`.
- Reference files used: Raw career-stage profile extract and general performance guidance.
- Portfolio evidence sources used: one impact note, one approved feedback entry, current goals, and manager-calibration notes.

### Readiness Snapshot

The portfolio currently shows a useful broader-scope signal: the redesigned kickoff checklist made cross-functional planning easier to start by clarifying pre-work, owners, dependencies, blockers, and decision points. The evidence supports operational clarity and cross-functional enablement. It does not yet show sustained adoption, broad organizational impact, or business need for higher-grade scope.

### Strengths to Lean On

- **Creating clarity:** The checklist turned ambiguous kickoff expectations into named pre-work, owners, blockers, and decision points.
- **Cross-functional enablement:** The work helped contributors and project leads start planning with a shared operating model.
- **Leadership and communication:** The approved feedback signal supports this: a peer partner said the decision summary made follow-up easier.

### Gaps and Growth Opportunities

- **Partial evidence:** The example suggests broader-scope work, but only one project group is represented.
- **Missing evidence:** The portfolio does not yet show repeat use, adoption across multiple teams, measurable planning-quality improvement, or business need.
- **Needs manager calibration:** Raw role-reference coverage means the user should ask whether this kind of cross-functional enablement counts as target-grade evidence.

### Impact Narrative Opportunities

- Add audience scale: how many teams, contributors, or planning meetings used the checklist?
- Add outcome evidence: did kickoff meetings become clearer, shorter, or better prepared?
- Make the trade-off explicit: what did the user choose to standardize centrally versus leave flexible for teams?
- Add a clearer through-line: ambiguous kickoff expectations -> checklist intervention -> changed planning behavior.

### Behavioral Evidence (How)

The work shows leadership and communication through creating clarity for contributors and project leads. This maps most directly to Leadership and Communication, with possible Scope and Impact evidence if adoption expands beyond the first project group.

### Role Expectation Map

| Expectation | Evidence status | Supporting evidence | Coaching note |
|---|---|---|---|
| Create clarity across ambiguous work | Strong evidence | Kickoff checklist impact note and approved peer feedback | This is the clearest readiness signal. |
| Influence beyond one project group | Partial evidence | One checklist example | Capture reuse across additional projects before treating it as broad-scope evidence. |
| Demonstrate business need for higher-grade scope | Missing evidence | No source yet | Ask the manager whether this work maps to an org-level capability gap or priority. |
| Target-grade alignment | Needs manager calibration | Raw role-reference coverage | Use the raw profile as source material, not a final interpretation. |

### Business Need and Budget Boundaries

- **Business need:** Not yet evidenced. The portfolio does not show why the organization needs this work at a higher-grade scope.
- **Budget availability:** Not visible from the portfolio and cannot be assessed by AI.

### Manager Calibration Questions

- Does this checklist work count as target-grade scope, or does it need broader adoption first?
- Which evidence would make this a stronger promotion-readiness example?
- Does the org need this kind of cross-functional enablement at a higher-grade scope?
- What would you expect to see next if I wanted to turn this into a stronger readiness signal?

### Optional Promotion Justification Draft

Not recommended yet. The evidence is useful for a manager conversation, but the portfolio needs stronger adoption and business-need signals before this should become promotion justification language.

### Next Evidence Moves

- Ask your manager whether this work counts as broader-scope evidence or needs adoption across additional projects.
- Capture a usage or meeting-quality signal after the checklist is reused.
- Add feedback from a project lead or contributor who used the checklist in a real kickoff.
```

## Why it works

- It does not turn limited evidence into a promotion decision.
- It separates readiness, business need, and budget.
- It labels raw role-reference coverage honestly.
- It names strengths, gaps, and narrative opportunities before drafting any promotion copy.
- It gives manager-calibration questions instead of overclaiming.

## Privacy note

The example uses generic work, synthetic source paths, and no names, issue numbers, PR numbers, Slack URLs, customer names, compensation details, or recognizable incidents.

## Reuse path

Use this as a pattern for readiness coaching boundaries. Replace the synthetic evidence with your own captured impact notes, opted-in feedback, goals, manager calibration, and role references.
